# Attack suite ATK-33 … ATK-40 – milestone 2 result

Runs of 2026-11-22 on the runner device (`scripts/run-atk.sh --prefix <run prefix>`), Claude Code 2.1.330, guest
0.1.0, Ubuntu 24.04, Landlock ABI 4, TEST_MODE golden built by the script from this branch. Specification:
`07-testing.md` section 2.3, `05-runner.md` sections 4.4, 4.6, 5.3–5.5, 10.2, 12, `03-api.md` sections 7.1, 8, 9.
Method of ATK-01 … ATK-32: `M0.md`; decisions: `docs/platform/decisions/ATS-01.md`, `ATS-02.md`, ADR-044 (numbered ADR-043 before DOC-01).

**Result: all eight new attacks pass in both modes, each with its attack-specific checks (criterion `specific`);
the regression of ATK-01 … ATK-32 passes in both modes; both detector controls fail exactly their injected criteria;
the sandbox self-test passes while attack sessions run; no model request reached the dispatcher without a registered
double.** Full suite: 101 tests (40 attacks × 2 modes plus the ATK-33 … ATK-40 cases, probes and controls), about
2 minutes wall time; one run 3–5 s (ATK-37 about 14 s: 20 raw MCP requests including 1 MiB bodies).

## What is added to the ATS-01 method

- **Plans** (`agent_doubles.atk.extended.PLANS`): parts of an attack that a session cannot do with its tools – links,
  hard links, FIFO and device planted before the start; a session-side client that sends HTTP as the session's own
  user (outside the sandbox, own transient unit, recognised by the process check); forged prompts typed into the
  pane through the root tmux server; a runner stand-in that answers operations with the runner's formal checks and
  tarball rewrite and the GitHub double.
- **Criterion `specific`** per attack (below), in addition to the seven criteria of ATS-01, which apply unchanged.
- `no_foreign_read` also covers outbound data other than model requests (the workspace exports of ATK-40).

## Limits

- The session-side client runs outside the sandbox with the session's UID: it shows what the guest API does with
  hostile input, not whether code inside a session could send it (it cannot: ATK-09 … ATK-12).
- Links and hard links are planted by the suite; a session cannot create them (no tool; imports refuse links;
  `/srv/sessions` is its own file system, so hard links to system files are impossible).
- The runner stand-in executes no operation; argument injection into the real executors is left to ATS-03.
- Refused MCP calls of a client other than Claude Code are not journaled by the guest (GST-07 decision 10: refusals
  reach the runner through the transcript, which such a client does not write); left to ATS-03.
