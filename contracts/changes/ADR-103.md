# ADR-103 – contract changes

ADR-027 section 3 (additive). Decision: ADR-103 (remote control by VNC when a process needs a human).

## Device requests
- New kind `vnc.open` (`requests/vnc.open.*`, `common.json` `request_kind`): root `{kind: "login"|"session", id}`;
  responses `{step: "vnc", key, password, idle_seconds}`, final `{step: "done", reason}` or `failed`.
- `requests/objects.json` `failure_code`: new `no_screen`.
- `claude.login`: root gains the optional `vnc: true`; responses gain the step `needs_human {vnc_available}` (only to a
  root with `vnc`).

## API
- `GET /v1/vnc/{request}` (owner, WebSocket) and `GET /v1/device/vnc/{request}` (device_addressed, WebSocket):
  the two ends of a VNC tunnel (`ws/vnc/query.json`, `ws/vnc/record.json`).

## Audit
- New actions `vnc.connect` (empty detail) and `vnc.close {reason, seconds, bytes}` (`enums/audit-actions.json`,
  `audit/vnc.*.json`).
