## Open risks carried into M1

- GitHub Actions do not run for the integration branches; the local gates stay binding.
- The guest reaches test doubles over the Lima host address, but credential upstreams allow `http://` only to loopback
  (DBL-01, GST-04): SCN-01 must settle TLS for the doubles or a test-mode upstream rule.
- Claude Code 2.1.330 sends no `SessionStart` hook before the first prompt (ADR-029): RUN-04/GST-05 take
  `prompt_delivering` from the transcript or pane.
- Session user names derive from the millisecond prefix of the UUIDv7 session ID; two sessions of one VM in the same
  millisecond collide (GST-02, ATS-01) – to be fixed with RUN-04/GST-05.
- The hub exits with −15 after an orderly SIGTERM shutdown (uvicorn re-raise, HUB-02); relevant for supervisors.
