# E-43 – contract changes

[KONZEPT E-43](../../docs/platform/KONZEPT.md#e-43) (additive).

## `enums/ui-views.json`: view type `task.terminal`

The task page has a new first tab "Claude Code" (`?tab=terminal`, the default): the terminal of the main session with
the prompt input below it. The UI health report names it as the view type `task.terminal` with the pattern
`/o/:org/t/:task#terminal`, listed before `task.chat`. A hub that does not know the type yet counts it as `other`, as the
file says; the hub's copy (`agent_hub.telemetry.views`) carries it.
