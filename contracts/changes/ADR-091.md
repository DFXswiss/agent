# ADR-091 §3 (correction of 2026-11-26) – contract changes

ADR-027 section 3 (additive). Decision: ADR-091 section 3 (every subscription at a glance: what is left, the binding
window, usable now and the next release by the rule of ADR-081 section 6).

## API (`api/objects.json`)
`subscription_row` (`GET /v1/me/subscriptions`) adds the optional `state` (null without a reading); new object
`subscription_state {usable, binding, release}`: the state of one subscription by the rule of the summary of
`GET /v1/orgs/{org}/quotas` (`agent_hub.models.quotas`), for the primary record exactly the one that summary counts.

`GET /v1/orgs/{org}/quotas`: `used_percent` / `resets_at` of an operator subscription are those of its binding window
(a window whose reset has passed counts 0, the week on a tie); the form is unchanged.
